### ClickFix command put on the clipboard

`clickfix_clipboard_command` · critical · score 80 · ATT&CK T1204.004, T1059 · tags clickfix

The page put a command on the clipboard. The command has a ClickFix trait, or the page tells the visitor to paste it into the Run dialog or a terminal. ClickFix traits: a download cradle, hidden or encoded PowerShell, mshta of a URL, a finger.exe or for /f fetch-and-run, caret obfuscation, or a fake-CAPTCHA comment or padded decoy.

Rule: [`sandbox/detections/rules/clickfix/clickfix_clipboard_command.kql`](../sandbox/detections/rules/clickfix/clickfix_clipboard_command.kql)

```kql
// A clipboard command with a ClickFix trait, or any clipboard command on a page that
// tells the visitor to paste into Run or a terminal.
clipboard_commands
| where trait in ("unambiguous", "cradle") or exists(run_dialog_pages)
| project command = substring(text, 0, 1000), trait, api, frame_url
```

`local_port_scan` · medium · score 25 · ATT&CK T1046, T1592.004 · tags fingerprinting, local-port-scan

```kql

| summarize ports = make_set(port), hosts = make_set(host), channels = make_set(channel),
            scripts = make_set(script), host_count = dcount(host),

                      iff(isnotempty(loaded_vendor)
```

## Tables

What the capture holds. Tables describe; rules decide.

### `requests`

Every HTTP(S) request in the session's HAR, in order.

| Column | Meaning |
| --- | --- |
| `method` | GET, POST, ... (upper case) |
| `url` | The full URL |
| `host` | The host name, lower case |
| `path` | The URL path |
| `query` | The query string |
| `headers` | Request headers by lower-case name: headers["origin"] |
| `post` | The request body text, or empty |
| `status` | The response status code |
| `resp_text` | The response body text the HAR kept, or empty |
| `cookies_set` | Names (lower case) of the cookies the response set |
| `resource_type` | document, script, xhr, image, ... |
| `document_host` | Host of the page that made the request, from the browser request log; empty when the capture has no request log or the request is not in it |
| `origin_host` | Host in the Origin header, else in the Referer header, else empty |

### `pages`

The raw HTML of every page snapshot taken in the session (hidden elements and inline scripts included). Empty for captures made before raw snapshots existed.

| Column | Meaning |
| --- | --- |
| `url` | The page URL |
| `host` | Its host, lower case |
| `html` | The raw HTML |

### `frames`

Every frame the browser rendered (live frames at the end of the session, then every page seen earlier), with its visible text and forms.

| Column | Meaning |
| --- | --- |
| `url` | The frame URL |
| `host` | Its host, lower case |
| `title` | The page title |
| `text` | The visible text (capped) |
| `prompt` | The strongest secret the frame asks for: password, payment, seed, otp or username (an email field counts only on a page about signing in); empty if none |
| `prompts` | Every secret the frame asks for |
| `email_only_form` | True when a form has an email field and no password field |
| `links` | Every link URL in the frame |
| `content` | The title and the visible text, joined by a space |
| `live` | True for a frame still open at the end of the session (false for a page seen earlier) |
| `top` | True for a top-level page: the main frame of an open tab, or a page seen earlier |
| `has_text_box` | True when the frame has a text box or text area to type into |
