# Sandboxer detection catalog

_Master list of every built-in detection shipped on the `detection-rules` branch. Generated 2026-10-24; keep it in step with `sandbox/rules/defaults.py`._

Totals: **52 built-in behaviour rules, 9 web YARA rules.** Suricata is loaded from external ET Open / local rule files (not enumerated here); feed matches emit `indicator` hits. Round legend: **baseline** = pre-existing before the detection-spec work, **R1 / R2** = added in the first / second detection-spec round.

## Other detection inputs

- **Suricata:** ET Open rules (imported as `sid:<n>`) plus local rules run over the session pcap when `SANDBOX_SURICATA_IMAGE` is set; each alert scores `suricata:alert` (20) x eve severity, capped at 45. Not individually catalogued here.
- **Threat-feed indicators:** IOC matches (domains, URLs, IPs, `eth_address`, hashes) score the `indicator` weight (60). The `eth_address` IOC type and clipboard-derived IOCs (DE-CFX-008) were added in R1.
