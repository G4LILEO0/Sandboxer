# Sandboxer detection catalog

_Master list of every built-in detection on the `detection-rules` branch. Regenerated 2026-10-25 from `sandbox/rules/defaults.py`; keep it in step._

Totals: **74 built-in behaviour rules, 10 web YARA rules.** Suricata comes from ET Open / local rule files (not listed); feed matches score `indicator` hits. Round legend: **baseline** = before the detection-spec work; **R1 / R2 / R3 / R4** = added in that round; **LR1** = live-sample round 1 ([live-round-1.md](live-round-1.md)). The *Changes* column marks rules modified in rounds 3, 4 and LR1. Spec IDs: `DE-*` from detection-spec.md / -loop1.md, `L2-NEW-*` from detection-spec-loop2.md, `LR1-*` from live-round-1.md.

## Live round 1 fact changes that affect several rules

- `js.code_exec_*` leave out the sandbox's own code: the runner drops `COLLECT_SCRIPT`, Playwright's `__pwInitScripts` wrappers and its `__pwWebSocketDispatch` relay before counting, and facts take them back out of stored captures via the code samples (LR1-01). Every rule and fact reading `js.code_exec_*` benefits.
- `lure.run_dialog_instructions` and `lure.fake_captcha` / `verification_wording` also read each raw DOM snapshot's full text, hidden elements included, in overlapping 4000-character windows; "press and hold the Windows key" counts as a Run/terminal step (LR1-02). Phone and payment-pretext facts still read visible text only.
- New facts: `brand.hosting_label`, `brand.favicon_lookups`, `brand.favicon_lookup_count`, `final.abuse_interstitial`. `flazio.online` joins `FREE_HOSTING`.

## Round-4 fact changes that affect several rules

- `js.dynamic_exec_*` still aggregates every sink; new `js.code_exec_count/_max_len/_max_entropy` cover eval/Function/string timers only (own 400-event budget in the hook), and the runner keeps up to 20 code samples (256+ chars, first 4 KB) for the linked-exec check.
- `web3.rpc_large_string_results` (ABI-decoded string answers of 512+ chars, batch-aware), `web3.rpc_result_linked_exec`; `web3.dapp_ui` reads wording from top-level frames only. New `web3.explorer_api_hosts`, `web3.explorer_dead_drop`, `web3.wallet_library`, `web3.drainer_lure`.
- ConsentFix/first-party loopback: each URL is paired with the host that produced it (redirect hop, navigation, Referer, A3 frame, link frame, DOM page, script frame); the submitted URL is never an origin. New `lure.paste_back_with_input`.
- `clipboard.clickfix_unambiguous` now also covers installer-host cradles with userinfo, an explicit port or dot-segments; repo prefixes match case-insensitively. New `clipboard.no_gesture_commands`; `clipboard.overwritten_command` now sees empty (blanking) writes.
- `websocket.foreign_count` (not allowlisted, not brand-owned); `forms.script_posted_credentials` looks one base64 layer deep (whole body or per form value).
- Brands: `acronym:XYZ` keywords match the upper-case word only, in the original-case title/headings, with a sign-in/tracking context; lookalike acronym combos need a context token. Existing deployments must add `acronym:UPS` to the UPS brand by hand (seeding merges domains only).
- New facts: `idp.device_code_*`, `idp.numeric_php_*`, `idp.fake_address_bar*`, `downloads.mislabeled_image(s)`, `navigation.protocol_handler_*`, `forms.apps_script_*`, `lure.fake_os_update_pages`. The runner adds `headings` and `loose_text_inputs` to each frame.

## Scope notes

- `crashfix_repair_lure` covers the page side of CrashFix only: the crash-repair popup plus a clipboard command or Run instruction. The malicious extension that freezes the browser is outside a URL sandbox.
- Line endings: facts.py, domains.py, engine.py, ingest.py and several other files are CRLF on `main`. They are kept CRLF on this branch, because normalising here would turn `git diff main..detection-rules` into whole-file rewrites. Normalise on `main` in its own commit.
