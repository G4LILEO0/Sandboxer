**Sandboxer 1.0 is available** 🎉

Sandboxer is our own URL sandbox. Give it a suspicious link, and it opens the link in an isolated browser, records what the page does, and gives you a verdict with the reasons for it.

**What you get**
- Automated runs, or live sessions where you control the sandbox browser
- A report with the verdict, the rules that matched, screenshots, video and IoCs
- An IoC lookup for URLs, domains, IPs, hashes and emails
- A "Report missed detection" button when Sandboxer gets a link wrong

**How to use it**
Open Sandboxer at http://<Sandboxer address>:8000/ from your work computer, and submit a link.

The release summary, the release notes and the detection guide are attached. Questions and missed detections: reply in this channel.
